# VENELUZ

Esta es una aplicación que tiene como objetivo llevar un registro independiente de los distintos eventos y fallas eléctricas en el país, construidos de forma comunitaria. Este repositorio contiene solo el backend y la API. Tiene como filosofía ser de código abierto y de libre acceso, respetando la privacidad, sin recolección de telemetría o identidad de los usuarios que colaboran creando los registros.
